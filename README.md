# 🖥️ HackTheBox

This repository contains my **Hack The Box writeups** as I develop my practical cybersecurity and penetration-testing skills.

Each writeup documents the techniques, tools, concepts, and lessons learned from completing Hack The Box machines and challenges.

## 📚 What I'll Cover

* 🔎 **Reconnaissance & Enumeration** — Identifying services, hosts, and attack surfaces.
* 🧩 **Vulnerabilities** — Understanding and analysing vulnerabilities discovered during each machine.
* 🛠️ **Tools Used** — Tools such as Nmap, Burp Suite, Metasploit, Impacket, BloodHound, and others.
* 💻 **Techniques** — Exploitation, privilege escalation, credential attacks, Active Directory techniques, and more.
* 🧠 **Things Learned** — Key concepts, mistakes, and lessons from each machine.
* 🛡️ **Mitigations** — Where appropriate, documenting how the vulnerabilities or attack paths could be prevented or detected.

## 🎯 Focus Areas

Depending on the machine or challenge, writeups may cover:

* 🌐 Network enumeration
* 🐧 Linux
* 🪟 Windows
* 🏢 Active Directory
* 🌍 Web applications
* 🔐 Authentication & credentials
* ⬆️ Privilege escalation
* 🧩 Vulnerability exploitation
* 🛡️ Detection & defensive security

## ⚠️ Disclaimer

All testing documented in this repository is performed against **Hack The Box's authorized training environments**.

Writeups will follow Hack The Box's applicable content and write-up policies, including restrictions around publishing solutions for active machines.

The techniques documented here are intended for **education and authorized security testing only**.
